Codex Link Control Center
=========================

This folder is your local control panel for Codex Link.

Use these files:

1. Start Codex Link.cmd
   Opens visible windows for:
   - Codex Link Controller
   - ngrok tunnel

   Keep those windows open while you use Codex Link.

2. Open Dashboard.url
   Opens the local dashboard:
   http://localhost:8787/

3. Check Status.cmd
   Checks whether the controller and ngrok tunnel are reachable.

4. Stop Codex Link.cmd
   Stops the controller on port 8787 and stops ngrok.
